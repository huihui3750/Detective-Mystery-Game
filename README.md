# CASE 001：消失的緋紅之心

##  專案介紹
《消失的緋紅之心》是一款以 Python Flask 開發的網頁互動式偵探推理遊戲。
玩家將扮演偵探，透過調查犯罪現場、蒐集證據、訊問嫌疑人及分析線索，逐步還原案件經過，最終找出真相。
本專案結合傳統網頁互動設計與 AI 對話技術，希望提供具有探索性與推理性的遊戲體驗。

##  主要遊戲功能
- **案件調查**：探索不同地點，尋找與案件相關的線索。
- **證據蒐集**：取得並查看證據的詳細資訊。
- **AI 嫌疑人訊問**：透過 AI 對話功能與嫌疑人互動。
- **證據出示**：在訊問過程中向嫌疑人出示已取得的證據。
- **推理板**：選擇不同線索，建立有效的推理關聯。
- **偵探筆記**：自動整理調查發現與已完成的推論。
- **案件時間線**：查看事件發生順序，協助還原案情。
- **最終指控**：根據調查成果選擇嫌疑人，進入案件結局。

##  本機執行方式
1. 下載或複製本專案。
2. 安裝 Python 及專案所需套件。
3. 設定 `OPENAI_API_KEY` 環境變數，以啟用 AI 訊問功能。
4. 在專案資料夾執行：python app.py
5. 使用瀏覽器開啟終端機顯示的本機網址，開始遊戲。
> 注意：實際安裝套件方式及啟動網址，請以專案設定與執行結果為準。請勿將 API Key 上傳至 GitHub。

## 遊戲流程
案件介紹 → 現場調查與嫌疑人訊問 → 蒐集證據 → 整理時間線與偵探筆記 → 推理板建立關聯 → 最終指控 → 案件結局
